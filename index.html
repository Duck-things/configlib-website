Using ConfigLib

Configure, insert and derive FTC parts in Onshape without redesigning them from scratch. Here's how to get in and use the library.

Navigating Configuring Inserting Deriving Original doc ↗

Navigating ConfigLib

Step 1 — Opening ConfigLib

If you haven't already, fill out the access form to get into the library. Then open Onshape and find Teams in the sidebar — click to expand it, and click ConfigLib.

Step 2 — ConfigLib navigation

In the team menu you might not see every document, because they're grouped into folders. Click ConfigLib to expand them, then browse in. Opening -ELECTRONICS-, for example, brings up every electronics document.

The library on this site mirrors that structure if you'd rather browse here.

Configuring a part

The configuration menu sits at the top of the sidebar, above the feature tree. It changes size, shape and color quickly. There are three kinds of input.

Drop-down list

Selects between versions of a part. On the bearing, choosing goBILDA 8mm swaps the geometry to an 8mm ID goBILDA bearing.

Checkbox

A true / false switch. REX Bore decides whether the bore is REX — uncheck it and the bore becomes round.

Configuration variable

Takes a value: a string like a hex color, or a number for a dimension.

Heads up. Configuring a library document is only a view — you can't break the library by changing inputs.

Inserting into assemblies

  1. In your assembly, hit Insert.
  2. Switch to Other documents.
  3. Pick ConfigLib, then browse the folders. For a channel: -STRUCTURE- → C - Channel.
  4. Set the configuration — channel type, length, hole count, mount, color — click Generate, then click the part to insert it.

Deriving into a Part Studio

  1. In your Part Studio, open the Derived tool from the toolbar dropdown, or search for it.
  2. Click Other documents and browse for a part in the ConfigLib team.
  3. Configure the part and hit Generate.
  4. Click the check to derive it into your Part Studio. It stays linked, so library updates can be pulled in.

How to contribute

ConfigLib is only as good as its parts. Model something once with a configuration table and every FTC team that uses the library gets it — for good.

Request access to the team Join the Discord

Getting started

1

Fill the form

Request access so you can be added to the ConfigLib Onshape team with edit rights.

2

Say hi on Discord

Grab a part to work on so two people don't model the same thing. Ask questions there too.

3

Model it

Build the part in a new document with a configuration table for the options teams will need.

4

Submit for review

Drop it in the right folder and post it for review. Once checked it goes live for everyone.

Modeling standards

Keeps the library consistent so parts drop into anyone's robot the same way.

NamingOne document per part family, named C - Part (e.g. C - Bearing).
Config tableExpose real options as drop-downs, checkboxes or variables — not separate copies.
Clean rebuildEvery valid combination has to rebuild without errors before it ships.
Mate connectorsAdd connectors on the faces teams mate to, so inserting is painless.
FoldersFile it under -STRUCTURE-, -MOTION- or -ELECTRONICS-. Old versions go to Obsolete Files.

New to configurations? Read the guide first — it walks through the three input types on a real part.
